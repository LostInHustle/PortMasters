## 🛠️ 2. 运行游戏

当前版本 **v1.4.0** 为一款网页游戏，提供英文与简体中文两个入口页面，共用同一套游戏引擎。

文件：

- `PortMasters_Web_Edition/PortMasters_v1.4.0.html`（英文界面）
- `PortMasters_Web_Edition/PortMasters_MandarinEdition_v1.4.0.html`（简体中文界面）

无需构建、无需任何依赖。双击任一入口文件即可在任何现代浏览器中运行。入口页面会从旁边的 `css/` 与 `js/` 文件夹加载样式与脚本，因此复制或移动项目时请保持 `PortMasters_Web_Edition` 文件夹的完整。进度保存在浏览器本地存储中。首次启动会展示新手教程，逐步引导您完成第一次航程；游戏中随时按 F1 可查看完整规则。

### 🚀 可选的本地服务器

项目根目录下提供两个小型启动脚本，供偏好使用 `localhost` 地址的玩家以 8020 端口运行游戏。脚本仅使用 Python 标准库，任何 Python 3.8 或更高版本均可直接运行，无需安装任何东西：

- `PortMasters_v1.4.0.py` 打开英文版。
- `PortMasters_MandarinEdition_v1.4.0.py` 打开简体中文版。

```bash
python3 PortMasters_MandarinEdition_v1.4.0.py
```

脚本会为 `PortMasters_Web_Edition` 文件夹启动本地服务器，自动用默认浏览器打开对应版本的入口页面（`http://localhost:8020/` 亦可，会自动重定向到该页），并打印就绪提示。检测到局域网地址时，提示中还会给出同一网络其他设备可用的地址，同一网络下的手机或平板也能直接游玩。macOS 首次可能询问是否允许 Python 接受传入连接，选择允许后局域网访问才会生效；请避免在公共网络上长时间运行。在终端按 `Ctrl+C` 即可停止服务器。若 8020 端口已被占用，可在命令后附加其他端口号，例如 `python3 PortMasters_MandarinEdition_v1.4.0.py 8021`。

## 🎮 3. 游戏机制

游戏共包含 **8 次航程**，每次航程分为 **4 个阶段**：

- **阶段 1，港口采购**：在各大港口购买原材料或成品，也可在牙行密语板购买需求密语；每条探听到的密语都会在阶段 2 生成对应的订单。
- **阶段 2，贸易交易**：完成客户订单以获取金币与声望。
- **阶段 3，维护与工资**：支付船只维护费与工匠薪资，并结算生产。
- **阶段 4，船坞与模块**：升级船只以降低运费，并解锁模块槽位。
- 每个航程开始时会抽取一份**福缘**（航海家的罗盘），从加权池中抽出三份供您选择，选定一份，其效果持续整个航程：采购或运费折扣、额外产量、税收减免、即时金币、更便宜的雇佣等等。

### ⚓ 船只升级与模块

- 船只最多可升到 3 级，每升 1 级增加 1 个模块槽位，同时提高运费折扣。
- 共有 **8 种模块**：走私暗舱、散货索具、工匠工坊、避税账本、丝路垄断、牙行网络、打捞起重机、超载引擎。每种模块都改变经济系统的一条规则，可组合出独特的协同效应。
- 阶段 4 会提供一组 **3 张模块的抽取牌组**。本阶段内您可以反复安装模块，或用新模块替换已安装的模块。
- **每航程仅可更换一次抽取牌组。** 离开抽取界面再返回，展示的仍是同一组牌，绝不会自动刷新。抽取界面上有更换按钮，使用后本航程内按钮即失效，直到下一航程恢复。

### 📦 资源类型

- **原材料**
  - `麻布`，基础服装原料。
  - `丝绸`，高端商品面料。
  - `茶叶`，制作香囊的奢侈饮品。
- **成品**
  - `麻衣`，基础服装（织女制作）。
  - `布衣`，中级服装（织女制作）。
  - `绫罗绸缎`，高价值织物（纺织大师制作）。
  - `香囊`，奢侈香囊（香囊师制作）。

### 👷 工匠系统

- **织女**：制作麻衣与布衣。薪资：8金币/航程。
- **纺织大师**：可制作麻衣、布衣与绫罗绸缎。薪资：12金币/航程。
- **香囊师**：仅制作香囊。薪资：20金币/航程。
- **熟练度提升**：工匠累计生产足够物品后将升级，产出翻倍，薪资提高50%。若福缘提供雇佣折扣，本航程新雇佣的工匠在首次结算工资时享受该折扣。

### 💰 税收与财务

- **增值税**：约5%，针对成品利润征收。
- **所得税**：约10%，针对航程净利润征收。
- **运输费**：根据货物数量计算，再扣除船只等级折扣。  
  公式：`max(5, 货物数量×2 减去 船只等级×5)`

## ⌨️ 4. 操作指南

### ⚡ 键盘快捷键

- `Ctrl + S` 保存进度。
- `Ctrl + N` 进入下一阶段。
- `Ctrl + H` 结束阶段 1，打开工匠管理界面。

- 点击按钮确认操作（购买、交易、升级）。
- 在面板内滚动查看库存列表。

## 💡 5. 策略建议

1. **平衡开支**：切勿将所有金币用于采购，务必预留资金支付工资与维护费，避免破产。
2. **尽早升级**：船只升级能大幅降低长期运输成本，有盈余时优先升级。
3. **优化工匠**：解雇前确保工匠达到“熟练”状态，产出翻倍可大幅提升单航程回报率。
4. **商品选择**：成品利润高于原材料，但需计入增值税成本。
5. **模块取舍**：每航程只有一次更换牌组的机会，先安装或替换，再决定是否动用这次更换。
6. **税务规划**：接取高收益订单前，请提前估算所得税影响。

## 🧪 7. 测试

项目内置一套零依赖测试套件，需 Node 16 或更高版本：

```bash
node tests/run.js
```

测试包括：经济公式的单元测试；为每个船只模块与每种福缘各设一条探针，锁定其对引擎的实际效果；冒烟测试，确认页面只加载真实存在的文件、引擎启动后全局处理函数齐全；校验测试，确认界面上的数字与实际收支一致、每条探听到的密语都会在阶段 2 生成对应的订单，且任何界面、日志或入口页面都不出现连字符或破折号；以及集成场景，用两种语言完整重放游戏，把每个渲染面板、每行日志与游戏状态同重构前的构建所录制的基线逐一比对。基线存于 `tests/fixtures/`；有意修改玩法或界面后，先在 `tests/harness.js` 中将其编码为规范化规则（可参考 `tests/README.md` 的有意差异清单），再用 `node tests/run.js --update` 重新录制并检查差异。完整说明与新旧构建之间的有意差异清单见 `tests/README.md`。

## 🛡️ 8. 故障排除

- **无法存档**：若浏览器询问是否允许存储数据，请选择允许；并确认未在隐私浏览窗口中禁用本地存储。
- **启动后空白页**：请确认 `css/` 与 `js/` 文件夹与入口 HTML 文件位于同一目录，并使用较新的浏览器打开。
- **旧存档显示异常**：v1.4.0 之前的存档仍可正常读取；物品名称与存档键均未更改。
- **启动脚本提示端口被占用**：8020 端口被其他程序占用。请关闭该程序，或用其他端口启动脚本，例如 `python3 PortMasters_MandarinEdition_v1.4.0.py 8021`。
- **局域网地址打不开**：`localhost` 能访问，但提示中打印的局域网地址打不开。在 macOS 上，防火墙询问时请允许 Python 接受传入连接（系统设置、网络、防火墙）；并确认服务器是用当前启动脚本重新启动的，支持局域网访问之前启动的实例只监听 `localhost`，需要重启。部分访客网络或公共网络会完全阻止设备之间的通信。
