## 🎮 3. 游戏机制

游戏共包含 **8 次航程**，每次航程分为 **4 个阶段**：

- **阶段 1，港口采购**：在各大港口购买原材料或成品，也可在牙行密语板购买需求情报。
- **阶段 2，贸易交易**：完成客户订单以获取金币与声望。
- **阶段 3，维护与工资**：支付船只维护费与工匠薪资，并结算生产。
- **阶段 4，船坞与模块**：升级商船以降低运费，并解锁模块槽位。
- 每个航程开始时会进行一轮**福缘抽取**（航海罗盘）。系统会根据您当前的处境从加权池中抽出三份福缘，选定一份，其效果持续整个航程：采购或运费折扣、额外产量、税收减免、即时金币、更便宜的雇佣等等。

### ⚓ 船只升级与模块

- 商船最多可升到 3 级，每升 1 级增加 1 个模块槽位，同时提高运费折扣。
- 共有 **8 种模块**：走私舱、散货吊装索具、工匠工坊、避税账本、丝绸之路垄断、牙行网络、打捞吊臂、超频引擎。每种模块都改变经济系统的一条规则，可组合出独特的协同效应。
- 阶段 4 会提供一组 **3 张模块的抽取牌组**。本阶段内您可以反复安装模块，或用新模块替换已安装的模块。
- **每航程仅可更换一次抽取牌组。** 离开抽取界面再返回，展示的仍是同一组牌，绝不会自动刷新。抽取界面上有更换按钮，使用后本航程内按钮即失效，直到下一航程恢复。

### 📦 资源类型

- **原材料**
  - `麻布`，基础服装原料。
  - `丝绸`，高端商品面料。
  - `茶叶`，制作香囊的奢侈饮品。
- **成品**
  - `麻衣`，基础服装（织女制作）。
  - `布衣`，中级服装（织女制作）。
  - `绫罗绸缎`，高价值织物（纺织大师制作）。
  - `香囊`，奢侈香囊（香囊师制作）。

### 👷 工匠系统

- **织女**：制作麻衣与布衣。薪资：8金币/回合。
- **纺织大师**：可制作麻衣、布衣与绫罗绸缎。薪资：12金币/回合。
- **香囊师**：仅制作香囊。薪资：20金币/回合。
- **熟练度提升**：工人累计生产足够物品后将升级，产出翻倍，薪资提高50%。若福缘提供雇佣折扣，本航程新雇佣的工人在首次结算工资时享受该折扣。

### 💰 税收与财务

- **增值税**：约5%，针对成品利润征收。
- **所得税**：约10%，针对航程净利润征收。
- **运输费**：根据货物数量计算，再扣除船只等级折扣。  
  公式：`max(5, 货物数量×2 减去 船只等级×5)`

- `Ctrl + S` 保存进度。

## 💡 5. 策略建议

1. **平衡开支**：切勿将所有金币用于采购，务必预留资金支付工资与维护费，避免破产。
2. **尽早升级**：船只升级能大幅降低长期运输成本，有盈余时优先升级。
3. **优化工匠**：解雇前确保工匠达到“熟练”状态，产出翻倍可大幅提升单回合回报率。
4. **商品选择**：成品利润高于原材料，但需计入增值税成本。
5. **模块取舍**：每航程只有一次更换牌组的机会，先安装或替换，再决定是否动用这次更换。
6. **税务规划**：接取高收益订单前，请提前估算所得税影响。

## 🏁 6. 游戏结局与评级

完成 **8 次航程**后，游戏将根据 **声望** 进行最终结算：

- **声望 ≥ 300**：👑 丝绸之路霸主
- **声望 ≥ 200**：🏆 海上贸易大亨
- **声望 ≥ 100**：⭐ 成功商人
- **声望 ≥ 50**：👍 合格商人
- **声望 < 50**：🌊 新手商人

## 🛡️ 7. 故障排除

- **无法存档**：请确保项目文件夹具有写入权限，并检查杀毒软件是否拦截了 JSON 文件生成。网页版若浏览器询问是否允许存储数据，请选择允许。
- **启动崩溃**：确认 Python 版本 ≥3.8。部分旧版系统可能缺少 `tkinter` 组件。网页版若出现空白页面，请尝试更换现代浏览器。
- **黑屏或界面异常**：更新显卡驱动；若因 DPI 缩放导致显示异常，请尝试以管理员身份运行。
